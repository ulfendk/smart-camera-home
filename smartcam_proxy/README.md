# SmartCam

Opens the [SmartCam](https://github.com/ulfendk/smart-camera-home) web UI in the Home Assistant
sidebar, behind Home Assistant's login, and wherever you reach Home Assistant from, including
remotely. Live view, events and clips all work through it.

SmartCam itself runs elsewhere (for example in Docker on another machine); this add-on only
forwards to it. Adapted from the [Frigate Proxy](https://github.com/blakeblackshear/frigate-hass-addons)
add-on.
